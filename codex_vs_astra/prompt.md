# Youtube영상 공유게시판 앱 바이브 코딩 

# 기술 스택 
- 기술 스택 문서는 rules.md 파일 참고할 것 
- DB: ORACLE 18C XE 개발서버 보유 로그인가능
- Back-End package 명: kr.co.tkinfo.watchlater

# DB접속정보
- 192.168.45.2
- 1521
- XEPDB1
- USERSTK9
- PwUserStk9

# 기능 
- 첫페이지에 모든 목록이 표시된다. 
- 일단 목록에서 페이징은 사용하지 않음.
- 로그인 : 로그인 아이디, 비밀번호 (기본값 등록)
- 게시물 등록 : 제목, 영상URL, 내용
- 등록항목: 신규, 완료 구분 항목 
- 내용 수정 기능 : 제목, URL, 내용 
- 게시물 삭제 기능 
- 게시물 목록 보기 기능 
- 목록에서 영상 바로가기 기능
